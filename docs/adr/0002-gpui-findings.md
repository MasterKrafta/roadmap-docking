# ADR 0002 — результаты проверки GPUI

**Статус:** ожидает выполнения R0.3 на Windows 10.

Проверить и записать фактические результаты:

- [ ] окно запускается на Windows 10 x64;
- [ ] стандартное изменение размера окна работает;
- [ ] мышь и удержание кнопки работают, включая выход курсора за границы окна;
- [ ] клавиатура и перерисовка работают;
- [ ] DPI 100 %, 125 %, 150 % и 200 %;
- [ ] доступны overlay/drop-zone слой и перехват ввода на время drag;
- [ ] выбранный тестовый контекст GPUI позволяет тестировать интерактивное поведение.

## Передача Theme

Стартовое решение: явная передача одного `Theme` в root view. Это позволяет обходиться без глобального состояния и проверять тему в тестах. Пересмотреть в R1.6, если эксперимент R0.3 выявит существенное ограничение GPUI.

## Результаты запуска

Заполнить вручную на тестовой Windows-машине: ОС/build, GPU/драйвер, toolchain, commit GPUI, команды, результаты и известные ограничения.
