# ADR 0000 — инвентаризация репозитория

**Статус:** исходная инвентаризация существующего репозитория не выполнена — в запросе не было приложено исходного checkout. Создан новый базовый workspace по Roadmap 2.0.

## Создано

- workspace с `app` и crates `dock-core`, `dock-gpui`, `ui`, `platform-api`, `platform-windows`;
- закреплённый toolchain;
- скрипты качества и документация архитектуры;
- начальные `Theme`, `DockMetrics`, `Profile` и key-типы;
- минимальное окно GPUI для проверки старта.

## Перед R0.1 в существующем репозитории

Если проект нужно интегрировать в уже существующий код, сначала сравните существующие модули, тесты, команды и зависимости с этим каркасом. Не перезаписывайте существующую реализацию без инвентаризации.
