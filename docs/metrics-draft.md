# Предварительные метрики

Значения здесь предназначены для запуска каркаса, не являются утверждённой спецификацией Photoshop. Значения из Roadmap, явно указанные в доступном фрагменте: ширина колонок 280 px, минимальная ширина 200 px, ширина rail 36 px, максимум 4 колонки. Остальные числа — стартовые значения-заглушки до сверки с полным приложением A.2.

| Метрика | Значение | Статус |
|---|---:|---|
| Высота общего заголовка | 32 px | предварительное |
| Высота полосы вкладок | 28 px | предварительное |
| Размер кнопки | 24 px | предварительное |
| Промежуток кнопок | 4 px | предварительное |
| Внутренний отступ | 8 px | предварительное |
| Толщина splitter | 4 px | предварительное |
| Hit-zone splitter | 8 px | предварительное |
| Ширина колонки по умолчанию | 280 px | требуется проверка |
| Минимальная ширина колонки | 200 px | требуется проверка |
| Ширина rail | 36 px | требуется проверка |
| Минимальная высота группы | 80 px | предварительное |
| Высота свернутой группы | 28 px | предварительное |
| Минимальная ширина Canvas | 320 px | предварительное |
| Максимум колонок | 4 | требуется проверка |

Все размеры — логические пиксели. Не переносить эти значения в render-код: UI получает их из единственного `Theme`, ядро — через `DockMetrics`.
