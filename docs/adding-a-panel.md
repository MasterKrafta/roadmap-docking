# Добавление панели

Инструкция будет уточнена в задачах реестра панелей и сохранения раскладки. Базовые правила:

1. Стабильный внешний ключ панели задаётся через `PanelKey`; внутренний slotmap ID не сохраняется в файле раскладки.
2. Регистрация панели выполняется в `app`, а не в `dock-core`.
3. Ядро оперирует моделью панели и командами, не знает о GPUI-сущности содержимого.
4. Панель не должна получать отдельный экземпляр `Theme`; используется общий объект приложения.
