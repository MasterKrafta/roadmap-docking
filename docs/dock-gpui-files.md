# Файлы `dock-gpui`

Краткий справочник по назначению файлов crate `crates/dock-gpui`.

## Назначение crate

`dock-gpui` связывает модель компоновки из `dock-core` с GPUI: принимает действия пользователя, рассчитывает геометрию кадра и рисует панели, вкладки, rail-колонки, меню и плавающие окна.

## Как устроен поток

```text
entry → MainWindow / DockController → FrameGeometry → surface / layers → components
```

Пути в таблицах указаны относительно `crates/dock-gpui/`. Перечень включает настройки crate, пример, исходники `src/` и интеграционные тесты `tests/`. Unit-тесты, расположенные внутри `.rs`-файлов, отдельно не перечисляются.

## Корень crate

|---|---|
| `Cargo.toml` | Настройки crate: зависимости, связь с dock-core/GPUI и включение feature serde у dock-core. |

## src/ — основные модули

| Файл | Что делает |
|---|---|
| `src/chrome_geometry.rs` | Рассчитывает дополнительную геометрию оформления dock-групп: заголовки, полосы вкладок, drag-grip и элементы icon rail. |
| `src/color.rs` | Содержит вспомогательное смешивание RGB-цветов, например для активной и неактивной подсветки drop-зон. |
| `src/entry.rs` | Точка запуска GPUI-окна: RunOptions, старт приложения и путь workspace.json по умолчанию. |
| `src/frame.rs` | Создаёт общий снимок геометрии кадра, нормализует прямоугольники и кэширует принадлежность узлов областям для рендера и drop-зон. |
| `src/geometry.rs` | Общие геометрические операции UI-адаптера: перевод прямоугольников в локальные координаты, прокрутка/обрезка и объединение границ. |
| `src/host.rs` | Контракт DockHost: приложение сообщает заголовки и значки панелей, рисует их содержимое и получает callback-обработчики команд, drag и resize. |
| `src/labels.rs` | Централизованные подписи встроенного окна и правила текста для вкладок и записей боковой rail-панели. |
| `src/lib.rs` | Корневой модуль библиотеки: объявляет внутренние модули и экспортирует публичный API dock-gpui. |
| `src/main_window.rs` | Состояние и рендер основного окна: события мыши/клавиатуры, меню, команды, undo/redo и автосохранение рабочего пространства. |
| `src/metrics.rs` | Переводит ThemeMetrics UI в DockMetrics, которые использует dock-core при расчёте геометрии и ограничений. |
| `src/render.rs` | Публичные функции рендера: строят поверхность из Layout/прямоугольников либо из готового FrameGeometry через DockHost. |
| `src/requests.rs` | Семантические типы UI-запросов: какой handle меняют при resize, какое меню открыть и какие данные нужны для overlay перетаскивания. |
| `src/surface.rs` | Собирает целую поверхность dock в фиксированном порядке слоёв и передаёт им Layout, геометрию, тему и DockHost. |
| `src/tree_query.rs` | Запросы по дереву layout: активная панель, узлы поддерева, группы заголовка плавающего окна и узел drop-цели. |

| `src/components/panel_tab.rs` | Рисует вкладку панели: активное состояние, hover и focus; обрабатывает клик, двойной клик и клавиатурное перемещение. |

| `src/components/tab_overflow_button.rs` | Кнопка «⋯» для открытия списка вкладок, которые не поместились в полосе вкладок. |

## src/dock/ — команды и управление состоянием

| Файл | Что делает |
|---|---|
| `src/dock/commands.rs` | Фабрики DockCommand для типовых действий: активировать/свернуть вкладку, сменить режим колонки, открыть/закрыть панель или floating-группу. |
| `src/dock/controller.rs` | Владелец текущего Layout: применяет команды через историю, ведёт drag/resize-сессии, undo/redo и согласует состояние с геометрией окна. |
| `src/dock/controller_tests.rs` | Модульные тесты DockController: операции с layout и историей, drag/drop, resize, обработка ошибок и узкого viewport. |
| `src/dock/drag_session.rs` | Состояние жеста drag: порог старта, исходная точка, снимок геометрии и защита от использования устаревших drop-зон. |
| `src/dock/drop_commit.rs` | Преобразует завершённый drag в семантическое действие dock-core и подбирает bounds, если результатом должно стать плавающее окно. |
| `src/dock/floating_policy.rs` | Рассчитывает начальные границы floating-окна, сохраняет смещение захвата мышью, ограничивает позицию viewport и ищет окно под указателем. |
| `src/dock/host_impl.rs` | Реализация DockHost для встроенного окна: связывает визуальные callback-и с командами, меню и resize/drag обработчиками MainWindow. |
| `src/dock/keyboard.rs` | Переводит сочетания клавиш GPUI в глобальные действия: undo/redo и переключение видимости chrome. |
| `src/dock/mod.rs` | Объявляет dock-подмодули и предоставляет внутренние реэкспорты контроллера, команд, политик и сохранения workspace. |
| `src/dock/rail_policy.rs` | Автоматически выбирает переход между расширенной колонкой и rail по ширине; использует гистерезис, чтобы режим не дрожал у порога. |
| `src/dock/resize_session.rs` | Измеряет исходную геометрию при начале resize, рассчитывает перемещение указателя и превращает его в команды для разделителя, колонки, flyout или floating-окна. |
| `src/dock/workspace.rs` | Загружает, проверяет, сериализует и атомарно сохраняет workspace.json; временный файл переименовывается только после записи. |
