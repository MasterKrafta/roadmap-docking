# Структура dock-gpui

В crate оставлена одна реализация dock: `src/next_dock/`. Старые controller/render/main-window ветки удалены. Файлы в `src/components/` — только общие визуальные примитивы, которые использует новая реализация.

## Публичная точка входа

| Файл | Назначение |
|---|---|
| `src/lib.rs` | Публичный API: `run(RunOptions)` и параметры запуска окна. |
| `src/next_dock.rs` | Запуск GPUI-приложения, создание главного окна и подготовка первого скрытого floating-окна. |

## Единственная реализация: `src/next_dock/`

| Файл | Назначение |
|---|---|
| `model.rs` | Модель дерева: `Split`, `Column`, `Tabs`, группы вкладок и контейнер независимых композиций. Здесь выполняются операции изменения дерева. |
| `geometry.rs` | Геометрия узлов, минимальная ширина композиций и распределение размеров по весам. |
| `view.rs` | Отрисовка dock-композиций, разделителей, плавающих представлений и drag/drop-превью. |
| `window.rs` | Состояние главного окна, обработка перетаскивания групп/вкладок, reorder, resize и управление плавающими композициями. |
| `floating_window.rs` | GPUI view отдельной плавающей композиции. |
| `native_floating.rs` | Windows-интеграция нативных PopUp-окон: подготовка скрытых поверхностей, назначение owner, позиционирование, показ, скрытие и повторное использование. |
| `components/column_header.rs` | Заголовок колонки, зона перетаскивания и кнопки управления. |
| `components/dock_column_view.rs` | Компоновка заголовка колонки и её содержимого. |
| `components/floating_composition_view.rs` | Рамка и размещение floating-композиции внутри поверхности. |
| `components/group_header.rs` | Полоса вкладок, расчёт ширин, зона перетаскивания группы и меню. |
| `components/group_menu_button.rs` | Кнопка меню группы. |
| `components/panel_tab.rs` | Отображение отдельной вкладки. |
| `components/tab_group_view.rs` | Сборка рамки, заголовка, вкладок и содержимого группы. |

## Общие визуальные примитивы: `src/components/`

Здесь оставлены только используемые новой реализацией элементы: `GroupFrame`, `PanelSurface`, `RectBox`, `IconButton`, `SplitterHandle`, `TabStrip` и `with_focus_ring`, а также типы callback-ов GPUI.

## Граница с dock-core

Текущая модель `next_dock` владеет собственными узлами и операциями дерева. `dock-core` используется здесь для общих геометрических типов (`Axis`, `Point`, `Rect`, `Size`), но `DockController`, команды Core и workspace-сериализация в этой реализации не подключены. Сам crate `dock-core` в workspace не удаляется.

## Тесты

Модульные тесты модели находятся рядом с ней в `src/next_dock/model.rs`. Старые интеграционные тесты frame geometry и workspace round-trip относились к удалённому API и удалены вместе с ним.
