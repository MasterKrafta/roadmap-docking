# Язык встроенного интерфейса

Текущее reference-окно библиотеки поддерживает один язык пользовательского интерфейса — русский. Отдельного переключателя языка и runtime-инфраструктуры локализации сейчас нет: добавлять их следует только при появлении реальной потребности во втором языке.

Пользовательские подписи и резервные строки встроенного окна централизованы в `crates/dock-gpui/src/labels.rs`. Это включает подпись меню панелей, fallback для неизвестной панели, заголовок плавающей группы и пояснение при ошибке вычисления геометрии.

Технические идентификаторы, сообщения в логах и диагностические детали ошибок могут оставаться на английском. Тексты и содержимое, которые приложение передаёт через собственную реализацию `DockHost`, принадлежат встраивающему приложению и не переводятся библиотекой.

Параметры геометрии popup-меню (ширина, высота строки и горизонтальный отступ) настраиваются через `ThemeMetrics`; значения по умолчанию сохранены.
