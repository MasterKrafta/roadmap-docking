# Профиль Photoshop: рабочий контракт

Это сжатая фиксация требований из предоставленного Roadmap; это не означает, что всё входит в первый MVP.

## Иерархия

`DockArea → Column → Group/Tabs → Panel`.

- Колонки стоят рядом по горизонтали.
- Группы располагаются друг под другом внутри колонки.
- Вкладки живут в полосе группы.
- Произвольные вложенные split в `Profile::Photoshop` запрещены.
- Колонка хранит собственные ширину и режим, и валидна с одной группой.

## Защищённые области и временные слои

- Canvas обязателен, располагается вне dock и не может стать панелью, вкладкой или floating group.
- Flyout — единственный одновременно открытый временный слой поверх рабочей области; он не перестраивает базовую раскладку и не сдвигает Canvas.
- Порядок icon rail/flyout следует порядку групп и вкладок модели. Переключение режима колонки сохраняет состав, порядок и активные вкладки.
- Внутренние floating-группы находятся внутри главного окна; вертикальный стек; нативные окна ОС не входят в MVP.

## Resize

- Внутренняя граница двух колонок меняет ширины соседей согласованно одной атомарной командой `ResizeColumnBoundary`.
- Граница Canvas и крайней колонки меняет ширину крайней колонки, Canvas получает остаток.
- Двойной клик по горизонтальному разделителю групп вызывает `ResetColumnRatios { column }` через `Layout::apply` и восстанавливает равные доли высоты групп выбранной колонки.
- Координаты и размеры — логические px (`f32`); допуск px — `1e-3`, допуск долей — `1e-4`; NaN и бесконечность отклоняются.
- DPI-проверка: 100 %, 125 %, 150 %, 200 %; физическое округление — на границе отрисовки.

Неопределённые детали фактического поведения Photoshop остаются открытыми до проверки на реальном приложении и не блокируют статическую композицию.
